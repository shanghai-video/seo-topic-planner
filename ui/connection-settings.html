DataForSEO connection

Connect live DataForSEO research. Authorization happens in your browser; this Plugin never asks for, receives, or stores your DataForSEO login or password.

  1. Choose Connect DataForSEO below.
  2. Approve the DataForSEO authorization in the browser tab that opens.
  3. This screen finishes the official DataForSEO MCP connection and stores a short-lived token locally (user-only file).

Live research is available only when the status reads LIVE / READY. Until then the status reads AUTH_REQUIRED and research is refused; there is no demo mode. Disconnect deletes the locally stored authorization and returns the Planner to AUTH_REQUIRED.
